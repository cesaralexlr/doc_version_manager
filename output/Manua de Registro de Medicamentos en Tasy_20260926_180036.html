1 Introducción

El presente manual es una guía técnica para la configuración completa del catalogo de medicamentos para el Centro Médico ABC, sus flujos y reglas son propias de la institución, con Tasy EMR 5.03.

1.1 ¿Cómo utilizar este manual?

Con el objetivo de tener una lectura ágil se explicaciones breves y diagramas. A menudo se incluyen hipervínculos para evitar la repetición de pantallas, y crear una navegación referencial.

Nota: LA información como notas aparece en cursiva al final de un bloque para incluir flujos alternos o configuraciones adicionales, así como algunas excepciones a las reglas generales.

En el caso de necesitar nombrar algo importante:

1.2 Arquitectura y Lógica del Sistema Tasy

De forma muy breve, el sistema Tasy EMR opera mediante un modelo de base de datos relacional jerárquica que vincula catálogos maestros de artículos con reglas de negocio predefinidas. Esto se traduce en que ningún valor puede ser creado si no se configura un dato maestro y después una regla.

Ejemplo: para configurar una alerta, primero se registran los elementos en el catálogo. Al crear la vía "Intravenosa" y el medicamento "Potasio", el sistema les asigna automáticamente un número de identificación a cada uno (por ejemplo, ID 1 e ID 2). La regla de seguridad se programa uniendo exclusivamente esos números (ID 1 + ID 2 = Alerta). De este modo, si posteriormente se edita el texto de "Intravenosa" a "I.V.", la alerta sigue funcionando sin requerir ajustes, porque la base de datos continúa evaluando la conexión entre los códigos numéricos originales.

La interfaz gráfica de Tasy nos permite capturar esta información y reglas por medio de formularios dinámicos, la visión y edición de los mismos a su vez están controlados por la información del “Establecimiento”, “Perfil” y Sector”.
